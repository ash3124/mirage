# Mirage backend

This is the FastAPI backend for Mirage. The route and field contract is defined
by `API.md` at the repository root.

## Run

From the repository root:

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
$env:MOCK = "1"
python -m uvicorn app.main:app --reload --port 8000
```

The mock server reads contract fixtures from the monorepo's
`shared/examples/` directory and canned images/PDFs from `backend/assets/mock/`.
Keep `shared/` at the repository root alongside `backend/`.

For a normal server run, set `MOCK=0`. The SD 1.5 VAE loads during startup;
the img2img simulator pipeline also loads at startup when CUDA is available and
simulation is enabled. On CPU, cloak jobs use the reduced step count and the
simulator is unavailable. Job records and files expire after `TTL_SECONDS`
(900 seconds by default). Cloak processing uses `assets/target.png` when run
from this backend directory.
Certificate PDFs are generated by the backend. Watermark verification is
disabled until watermark support is implemented.

## Tests

From `backend/`:

```powershell
python -m unittest discover -s tests
```
